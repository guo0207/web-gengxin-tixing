# 🌐 网页更新自动监控提醒 (Web Update Notifier)

这是一个轻量、完全免费的网页更新监控工具。基于 **Python** 和 **GitHub Actions** 运行，无需拥有自己的服务器。只需配置好你想监控的网页元素和邮箱，它就会在云端全天候（或按你设定的时间频率）自动检测，一旦发现网页内容有更新，立刻发送邮件通知你。

## ✨ 特性
- **完全免费：** 依托 GitHub Actions 的免费算力，零服务器成本。
- **配置简单：** 修改几行代码即可监控任意网页的指定元素。
- **邮件提醒：** 稳定触达，支持 QQ、网易、Gmail 等主流邮箱。
- **免维护：** 部署完成后自动运行，无脑省心。

## 🚀 快速上手使用指南

如果你想使用这个工具监控你关注的网页，请按照以下步骤操作：

### 第一步：Fork 本仓库
点击页面右上角的 **Fork** 按钮，将这个仓库复制到你自己的 GitHub 账号下。

### 第二步：配置邮箱及授权码 (Secrets)
为了让程序能用你的邮箱自动发邮件，并且保证你的密码不被公开泄露，你需要配置 GitHub Secrets：

1. 进入你 Fork 后的仓库，点击顶部的 **Settings** 选项卡。
2. 在左侧菜单栏找到 **Secrets and variables** -> 点击 **Actions**。
3. 点击绿色的 **New repository secret** 按钮，依次添加以下 3 个密钥：
   - `SENDER_EMAIL`：填写你的发件邮箱地址（例如：your_email@qq.com）。
   - `SENDER_PASSWORD`：填写发件邮箱的 **SMTP 授权码**（注意：**绝不是**你的登录密码！请在邮箱后台设置中开启 SMTP 服务并获取授权码）。
   - `RECEIVER_EMAIL`：填写接收提醒的邮箱地址（可以和发件邮箱是同一个）。
